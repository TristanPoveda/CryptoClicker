# CryptoClicker

## Installation

### 1. Clone projet

```bash
git clone https://github.com/TristanPoveda/CryptoClicker.git
cd cryptoclicker
```
### 2. Download dependencies 
```bash
npm install
# or
yarn install
```

### 3. Run local server 

```bash
npm run dev
# or
yarn dev
```
## Technologies

-> React + TypeScript
-> Vite for build
-> CoinGecko API for crypto list
-> JSON backup + local loading
